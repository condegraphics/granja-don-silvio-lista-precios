# Brand spec — La Granja Don Silvio

## Activos aprobados

- Logo: `img/logo-la-granja-don-silvio.png` (PNG 560 × 298, entregado por el cliente en esta tarea). Se muestra sobre superficie blanca, sin redibujar ni recolorear.
- Referencia de composición: captura de tabla de pollo y modalidades provista por el cliente. Se utiliza para jerarquía de encabezados, columnas mayoristas y destaque de ofertas; no se replica como imagen.

## Identidad solicitada

- Paleta solicitada: rojo, verde y negro. Los valores CSS son tokens propuestos para este boceto a partir de la referencia visual, no un manual de marca oficial.
- Tipografía solicitada: familia Roboto, con fallback Arial/sans-serif.
- Acento amarillo: reservado para filas de ofertas, siguiendo la planilla/captura de referencia.

No se agregan logos, claims ni créditos de terceros.
